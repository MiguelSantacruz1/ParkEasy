# Atajos de teclado y ratón

## Editor del plano

| Acción | Atajo |
|---|---|
| Deshacer / rehacer | Ctrl+Z / Ctrl+Y (o Ctrl+Mayús+Z) |
| Copiar / pegar / duplicar | Ctrl+C / Ctrl+V / Ctrl+D |
| Seleccionar todo | Ctrl+A |
| Eliminar la selección | Supr o Retroceso |
| Cancelar lo que se dibuja o quitar la selección | Esc |
| Terminar polilínea, polígono o curva | Enter o doble clic |
| Girar 90° | R |
| Mover la selección 0,5 m (0,1 m con Mayús) | Flechas |
| Acercar o alejar | Rueda del ratón |
| Mover la vista | Botón central o derecho, arrastrando |
| Agregar varios elementos a la selección | Mayús + clic |
| Agregar un punto a un trazo seleccionado | Doble clic sobre el trazo |
| Quitar un punto de un trazo seleccionado | Doble clic sobre el punto |

Los atajos funcionan cuando el foco está en el plano. Si estás escribiendo en un campo del panel de propiedades, las teclas van al campo.

## Plano de Inicio

| Acción | Resultado |
|---|---|
| Clic en un puesto libre | Abre el registro de entrada con ese puesto |
| Clic en un puesto ocupado | Abre el registro de salida |
| Clic en un puesto bloqueado | Pide confirmar el desbloqueo |
